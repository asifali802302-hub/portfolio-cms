# Portfolio CMS

A full-stack Portfolio Content Management System built using React, Spring Boot, Java and PostgreSQL.

## Features

- Personal portfolio website
- About Me section
- Skills section
- Education and Career section
- Project management
- Separate Admin Panel
- Admin login
- Add projects
- Edit projects
- Delete projects
- PostgreSQL database
- REST API

## Technologies Used

- React
- Vite
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- HTML
- CSS
- JavaScript
- Maven
- Git and GitHub
